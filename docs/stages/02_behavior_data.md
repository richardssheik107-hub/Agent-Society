# B 系列：真人行为分布从哪里来，怎样校准而不写死日程

对应最初第二个问题。核心分工：金钱、库存、位置、交易和活动冲突由确定性代码处理；日记用于活动分类、时长、时段和转换分布；模型提出下一项行为。

## 数据来源与筛选

B1 的 ATUS 2025 下载受 HTTP 403 阻塞，保留失败来源登记，不把脚本完成当成数据已得到。随后 B1.1 接入 CTUR 发布的 NHAPS/AHTUS 1992—94 成人时间日记。

原包有 7,514 份背景/汇总记录与 125,554 个原始活动段。排除 173 份年龄缺失后得到 7,341 份有效成人日记，其中在职成人 4,774 份，在职工作日 3,215 份。每份核验 1,440 分钟、活动顺序及汇总一致性；成人样本内无无效日记、无汇总不一致。292 份零权重低质量成人记录仍在未加权语料中，不能把加权统计和语料抽样混为一谈。[依据：B1/B1.1](../reference/evidence.md#b1)

## 分类扩展做了什么

Core5 为睡眠、工作、进食、休闲、移动。B1.2 只比较四档：Core5、加个人护理、加家务、两者都加的 Core7，不任意挖新标签追求覆盖率。

| 样本与口径 | Core5 | Core7 |
|---|---:|---:|
| 全成人分钟覆盖 | 82.17% | 93.00% |
| 全成人原始活动段覆盖 | 66.64% | 90.68% |
| 在职工作日分钟覆盖 | 86.25% | 94.61% |
| 在职工作日活动段覆盖 | 68.32% | 91.54% |
| 在职工作日转换覆盖 | 47.11% | 81.35% |

转换覆盖使用每个分类方案自己合并后的转换分母，不能当作固定同一批转换的净提升。90% 是工程覆盖目标，不是“像真人”的科学标准。全成人样本需要加两个类别才超过目标；在职工作日只加家务就达到 91.03%。`OTHER` 不是 idle，更不是错误。[依据：B1.2](../reference/evidence.md#b1)

## 时长不能张冠李戴

在职工作日合并单次活动中位数：SLEEP 240、WORK 270、EAT 30、LEISURE 80、MOVE 15 分钟；个人护理 25、家务 30 分钟。全天总量是另一套统计，例如全天 WORK 中位 480 分钟，不能拿它直接替换一次 WORK。

原 WORK 90 分钟低于实证单次 IQR 180—460，提供校准理由；SLEEP 的单段可能被午夜切分，不能把 240 分钟当全天睡眠建议。原 EAT/MOVE 为即时后果，不能直接与真人占用时长相除。15 分钟 tick 的量化和具体模拟窗口还需明确。

## 日记的作用边界

日记提供群体参考，不指定 Alice 几点必须做什么；不是食品价格库、热量数据库或交易规则。1992—94 年美国样本与当代数字娱乐、目标人群有差异，未验证当代代表性。

研究结论：开放数据值得用于结构校准；跨人群迁移、再分发权限及未来数据升级仍需[人工讨论 D-07](../review/decisions.md#d-07)。原始数据留在受忽略本机目录，本文不上传它们。
