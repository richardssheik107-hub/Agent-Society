| 优先级 / 编号 | 要人决定的问题 | 目前依据 | 本次建议（待确认） | 不决定的风险 |

## 审核状态维护

只有人明确决定后才把“待审核”改成“已同意/否决/延后”，并写日期、证据版本和适用范围。一次同意某预算不等于无限重试授权。执行结果进入[验收账本](../current/acceptance.md)，不覆盖原讨论记录。
