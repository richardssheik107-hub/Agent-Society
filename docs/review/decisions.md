<a id="d-01"></a>
## D-01｜Q6.2 的对照设计、源产物和预算（P0）

**问题：** 要证明候选表达改善同一状态的选择，还是证明两条自主短链更稳定？两者不能混称。

固定状态配对能保持 A/B 真值相同，但不直接测长链；两条独立 world 的自主短链从第一次选择后就可能分叉，只能比较整体过程。建议先核对本机 `q61-runtime-01/attempt_3`，冻结固定状态小面板，再独立考察长链。八次请求只是曾提出的小预算候选，不是本次已批准额度。

需确认：样本状态、每臂请求数、AB/BA 顺序、主指标分母、服务失败处理、规则拒绝后是否运行另一臂、停止条件。主要看不可执行提议比例及成本；重复 MEAL 不默认计错误。仅增 executable_options，不同时增近期变化摘要。

需补：`source_artifact_verified=true` 的实际本机报告，或明确登记原文件不可得；匹配失败字段不能自动修成一致。建议审核角色：研究负责人。[依据](../studies/q62_action_projection.md)

<a id="d-02"></a>
## D-02｜是否增加购买游戏等“获取对象”活动（P0）

当前高层 JSON 不含 BUY，PLAY 也不代购。因此过滤未拥有游戏只避免拒绝，不创造可达的获取路径。备选：维持有限已拥有目录、显式采购宏活动、或把获取意图交给受约束计划器。

建议单独定义采购活动的预算、卖家位置、库存、旅行时间、中途失败和重复购买语义；不要改 Q6.2 的初始 ownership 来追求成功。需要成本和可达性测试。建议审核角色：规则负责人、研究负责人。[依据](../studies/q61_real_pilot.md)

<a id="d-03"></a>
## D-03｜对象目录、Top-K 与动态上下架（P1）

Q3 支持规范目录的一步接口优势，但没有比较千万全量呈现、每个世界有限目录、动态上架或偏好排名。建议后台目录与本次模拟的可见世界分开，有明确类目和数量上限，再评价动态事件。

需确认：哪些对象必须是真实名称，哪些可以是合成占位；属性来源/单位/版本；是否允许 NEW；新增对象如何审核身份和属性。不能把模型生成的热量直接标成实测事实。建议审核角色：规则负责人、数据负责人。[依据](../studies/q3_object_set.md)

<a id="d-04"></a>
## D-04｜Resource 保留字段与评价方法（P1）

最小集合尚未确定。R16→R32 的低收益不代表所有 32 维方案无效；R64 改善可能来自少量新增关键字段。建议先按任务和因果角色分类字段，再做相关投影消融。

需确认：后台真值与模型可见字段各自边界；聚合/细分字段是否重复；字段取值方向、单位、缺失值；对齐和 critical-miss 互补，不重复计为两个独立改善；日记 NA 的有效分母；预算与延迟怎样衡量。建议审核角色：研究负责人。[依据](../studies/q4_resource_visibility.md)

<a id="d-05"></a>
## D-05｜“正常长期行为”的正式标准（P0）

建议分三层：硬约束（不能凭空增钱、库存不能负、不能重复记账）；任务连续性（媒体实际进度、活动完成与恢复）；行为分布/个体偏好（什么时候进食、休闲多样性、长期需求是否异常）。只有前两层工程通过不能宣布第三层成立。

需确认：显式重看允许条件、是否允许跳集、连续进食如何解释、合理重复购买、睡眠/工作约束、异常循环阈值、评测时间窗与目标人群。不要从一条短链推断模型“不像人”，也不要用硬禁令强制好看的日程。建议审核角色：研究负责人、规则负责人。[依据](../studies/q6_continuity.md)

<a id="d-06"></a>
## D-06｜规则规模结论与真实目录里程碑（P1）

同意与否需要明确：Q5 通过的是固定合成类型/能力/模板索引，不是完整生产 RuleEngine 或数据库。备选下一步为真实小目录、热更新/下架压力、非算术检索，再逐档扩展；不优先购买大算力模拟虚拟 ID。

需确定类型增长、对象例外、规则版本迁移、库存竞争和存储负载。验收同时报告元数据、payload、总内存及延迟，不能只报一个 17.9 kB。建议审核角色：工程负责人。[依据](../studies/q5_rule_scaling.md)

<a id="d-07"></a>
## D-07｜行为数据的适用人群、年代和使用权限（P1）

现有日记可支持活动本体和时长结构，但与当代游戏/视频、目标地区生活方式不同。建议继续把日记作为软先验，世界合法性仍由代码定义。

需确认目标人群、数据升级需求、加权方式、OTHER 的保留与解释、不同人群的校准策略及分享权限。当前“研究可获取”不等于可任意再分发原始数据；本轮不重新作法律判断或上传数据。建议审核角色：数据负责人、研究负责人。[依据](../stages/02_behavior_data.md)
