## D-02｜对象获取与购买游戏活动（P0）

原高层 JSON 不含 BUY，PLAY 不代购。过滤非法 PLAY 不等于完成获取；M2 本轮已实现独立实验 JSON `{"activity":"ACQUIRE","target":"game_a"}`，仅显式 opt-in。

**已授权实验范围：** 可购买的非消耗性对象；共享 `_check_purchase()`/`_buy()` 与 commitment controller；同地零分钟购买，异地旅行后保存 BUY0，下一条明确 advance 再成交；获取不自动 PLAY。配置保存为 M2_ACQUIRE_V1，默认禁用且旧 world 不静默切换。已发生旅行保留，购买与完成原子化；账本、请求重放、恢复、暂停取消和 SQLite 并发按本轮验收记录核对。

**仍需人工决定：** 游戏能否重复购买；获取失败后如何继续；是否及何时自动旅行到卖家；动态库存和价格的更新方式；获取对行为选择的优先级；是否允许人物主动积累物品。本轮实验对已拥有游戏沿用共享规则拒绝，不等于这些产品问题全部被批准。

不修改冻结 Q6.2 世界或旧提示，不免费赋予游戏，不把购买塞进 PLAY。工程实现和测试结果见[M2 获取闭环](../studies/m2_object_acquisition.md)与[验收账本](../current/acceptance.md)；路线见[计划 M2](../current/plan.md#六m2补齐想玩游戏但没有游戏的合法路径)。审核角色建议：规则负责人、研究负责人。**D02_PRODUCT_SEMANTICS_APPROVED = NO；ACQUIRE_PRODUCTION_DEFAULT = DISABLED；后续真实请求需新授权。**
