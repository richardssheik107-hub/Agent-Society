“恢复 2401 次”是关闭/重新打开状态存储，不是 2401 次断电，也不是 2401 次分布式故障。另有独立子进程测试：进程在未提交事务中退出，重开后未提交修改回滚。

脚本每天观看一集，中间安排暂停。暂停时间不计入观看进度，恢复后继续未完成部分，默认下一次选择下一集。显式重看由单元测试覆盖：允许重看，但不能把旧集当成一次新的主线完成。

**这些数值证明受测工程机制保持一致，不证明模型可以自主正常生活七天或三十天。** 观察字符数也不是完整 prompt 字符数或 token 数，不能混用。

## 四、本轮交付内容

### 仓库与文档

更新失效的 Phase 0 README；统一 `docs/current/` 中文入口；旧计划/报告原文归档并保留旧路径跳转；停用两个写死旧实验 ID 的 A2 一次性补跑/回填入口。历史实验包和测试仍用于复现，没有因文件“旧”就直接删除。其他成员的 `delivery.*.jsonl` 原样保留，上游 gitlink 未改变。

### 事实与规则

人物—对象稀疏状态保存拥有量、观看集合、部分播放位置和游戏时长。相同对象别名指向同一 ID。购买和食用共享逻辑但读取各对象不同参数：购买扣钱，食用扣库存并更新饥饿和摄入热量，不重复扣费。

命令结果、事实、活动和事件同事务提交；同一 ID 的相同请求不会重复产生后果；同一 ID 换参数、基于过期人物版本的提案会被拒绝。并发抢最后一件库存和同一请求重复提交有测试覆盖。

### 连续活动

MEAL 自动完成必要的移动、购买和进食步骤，不在每个微步骤重新问模型；WATCH/PLAY/TRAVEL 等按实际模拟时间推进，支持暂停、恢复、取消和失败。中断、下架、失败不会伪造完成。

### AS2 适配与模型入口

薄适配器使用固定上游 `670c94fff7c64c4f79b632125f2ccf968155e746`，复用现有确定性 Router。真实 smoke 验证保存第 1 集第 10 分钟状态、恢复后看到下一集变为第 2 集，全程无模型调用。

受控模型入口已经提供：默认四次、最多十二次高层请求，必须显式 opt-in；持久预算在事务内检查，HTTP 超时、输出契约失败、规则拒绝与执行阶段失败分别记录，不保存原始 prompt/completion 或隐藏推理。

## 五、已知边界与未完成项

Q6 是独立实验运行层，不是未经审查就替换全部旧生产规则。WORK/SLEEP 等参数为合成工程参数；个人护理、家务等尚未构建完整心理/生理需求模型。当前候选接口仅服务小世界，不是千万目录搜索实现。

AS2 专项没有运行完整 Ray 多人社会，也没有证明分布式事务、跨机器 exactly-once 或长期自主行为。Q4 的动态相关 Resource 检索、实际对象目录压测、19 类意图交付验证、本地小模型对照仍按计划推进。

早期 CI 失败记录保留：包括漏装上游/异步测试依赖、MCP v2 与固定上游 v1 接口不兼容、历史语料缺失，以及未明确新版 Ruff 默认规则范围。修订说明与可复现命令见 [运行手册](runbook.md)。
