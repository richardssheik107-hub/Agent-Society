# 唯一现行计划：先证据、再设计、后真实实验

更新：2026-09-23。历史阶段文档只讲当时做了什么；下一步一律以本页和[人工审核记录](../review/README.md)为准。

## P0｜让已有结果可核对、可讨论

**1. 核验 Q6.1 原始产物。** 在有本机文件的研究分支运行 Q6.2 零请求核验。输出逐字段差异和真实 `source_artifact_verified`，不重跑旧 session，不用回放代替原 provider 证据。

**2. 冻结 Q6.2 小预算对照。** 先由人确认固定状态配对还是自主短链、主要指标、失败分母、顺序和预算，再实现/审阅正式入口。当前已核对代码只有投影和离线回放，真实 A/B CLI 与结果尚未证实存在。

**3. 审阅采购缺口与长期行为标准。** 游戏不可执行过滤不等于可以买到；重复进食不自动错误。D-02/D-05 独立讨论，不在投影实验中顺手改规则或饥饿参数。

验收门槛：源产物核验记录可追溯、实验协议获明确批准、默认零网络、失败不修复/补跑、对照只改变一项干预。没有批准前真实请求上限为 0。

## P1｜受控对照和状态表达

完成 P0 后才开展明确授权的真实 A/B；报告全部分配单元、成功/拒绝/超时与有效分母，保留失败。如果是真实短链，承认两臂后续世界分叉，不能作逐步同态因果比较。

Resource 相关投影是另一项研究；先审 Q4 的关键字段、补数指标和 EVAL NA，再做字段语义消融。活动候选、状态摘要、行为先验不可同时更改后统一归因。

## P2｜从短链逐步延长

只有短链接口与评价标准清楚后，才决定 12 次、半天、一天或多天；每次重新确定预算和停止条件。媒体进度、所有权和需求失衡用独立、明确标注的场景覆盖，不向旧实验中插动作。

本地小模型替换需同世界、同规则、同预算对照。远端参考模型结果不自动迁移到 8B/20B。

## P3｜真实目录和规则负载

保留共享模板，另测真实 payload、非算术检索、上架/下架、参数更新、例外规则与并发。Q5 的虚拟 10M 不是这个里程碑已完成。
